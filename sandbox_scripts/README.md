# Sandbox Scripts

该目录专门存放临时 / 实验性的脚本，便于快速试验导出、推理或性能验证流程。由于这里的脚本可能不具备长期维护价值，上层可以在需要时整体删除 `sandbox_scripts/`，而不影响核心代码。

## 使用约定

- **命名规则**：建议使用 `feature-purpose.py` 或 `task_description.md`，方便检索。
- **依赖管理**：脚本若依赖额外三方库，请在文件顶部或本 README 中注明安装方式；避免悄然增删核心依赖。
- **数据路径**：默认通过命令行参数传入模型、数据和输出路径，切勿硬编码到个人环境。
- **清理策略**：上游在发布或提交生产版本前可直接删除整个目录。若脚本有长期价值，请迁移到正式包结构或 `tools/` 中。

## 现有内容

- `onnx_sanity_check.py`：比较 Paddle Inference 与 ONNX Runtime 输出是否一致，帮助验证导出流程。详见脚本内说明。
