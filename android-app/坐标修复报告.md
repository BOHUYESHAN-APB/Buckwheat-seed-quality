# 坐标缩放问题修复报告

## 问题诊断

### 症状描述
用户反馈:
1. **Paddle标注图(`paddle_reference.png`)**: 标记正确,但位置/缩放有问题
2. **ONNX标注图**: 所有边界框堆积在左上角,且全是长条形

### 根本原因

通过调试发现:**模型输出的坐标未被缩放到原图尺寸**!

#### 技术细节:

1. **模型输入**: 
   - 图像被resize到 `800x800`
   - `scale_factor` = `[orig_w/800, orig_h/800]` 被传入模型

2. **期望行为**: 
   - 模型使用`scale_factor`自动将输出坐标缩放回原图尺寸

3. **实际行为**: 
   - **模型输出的坐标仍然是800x800尺度的!**
   - `scale_factor`被传入了,但**没有被模型用于缩放输出坐标**

4. **证据**:
   ```
   原图尺寸: 3468 x 4624
   Scale factor: [4.335, 5.78]
   
   模型输出坐标范围:
   - X范围: [31.5, 82.7]  ← 明显是800x800尺度
   - Y范围: [62.8, 123.4]
   
   手动缩放后坐标范围:
   - X范围: [136.7, 358.3]  ← 符合原图尺寸
   - Y范围: [363.0, 713.5]
   ```

5. **对比Paddle和ONNX**:
   - Paddle模型输出: 坐标范围 [31-123] (也是800x800尺度!)
   - ONNX模型输出: 坐标范围 [31-123] (一致!)
   - **两者都需要手动缩放!**

### 完整后处理流程

```java
public List<Detection> postprocess(
    float[][] rawDetections,
    int origWidth,
    int origHeight,
    int modelInputSize,
    float scoreThreshold
) {
    List<Detection> results = new ArrayList<>();
    
    // 计算缩放因子
    float scaleX = (float) origWidth / modelInputSize;
    float scaleY = (float) origHeight / modelInputSize;
    
    // 检查是否需要缩放
    float maxCoord = 0f;
    for (float[] det : rawDetections) {
        if (det[1] < scoreThreshold) continue;
        maxCoord = Math.max(maxCoord, Math.max(
            Math.max(det[2], det[3]),
            Math.max(det[4], det[5])
        ));
    }
    
    boolean needsScaling = (maxCoord < 1000);
    
    // 过滤和缩放
    for (float[] det : rawDetections) {
        float score = det[1];
        if (score < scoreThreshold) continue;
        
        int classId = (int) det[0];
        float x1 = det[2];
        float y1 = det[3];
        float x2 = det[4];
        float y2 = det[5];
        
        // 应用缩放
        if (needsScaling) {
            x1 *= scaleX;
            y1 *= scaleY;
            x2 *= scaleX;
            y2 *= scaleY;
        }
        
        // 限制在图像范围内
        x1 = Math.max(0, Math.min(origWidth, x1));
        x2 = Math.max(0, Math.min(origWidth, x2));
        y1 = Math.max(0, Math.min(origHeight, y1));
        y2 = Math.max(0, Math.min(origHeight, y2));
        
        results.add(new Detection(classId, score, x1, y1, x2, y2));
    }
    
    return results;
}
```

## 关键结论

### 1. 模型行为确认
- **Paddle和ONNX模型的`scale_factor`输入参数不会自动缩放输出坐标**
- 所有坐标都需要在后处理阶段**手动缩放**

### 2. 缩放公式
```python
scaled_x = model_output_x * (original_width / model_input_size)
scaled_y = model_output_y * (original_height / model_input_size)
```

### 3. 检测准确性
- Paddle: 25个检测 (score ≥ 0.5)
- ONNX: 25个检测 (score ≥ 0.5)
- **检测结果完全一致** → ONNX转换成功!
