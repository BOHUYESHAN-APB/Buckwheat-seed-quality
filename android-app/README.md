# Buckwheat Android — Documentation Index

The detailed Android documentation has been moved to the repository `document/android/` folder.

Main documents:

- `document/android/quickstart.md` — Quickstart and essential steps to run the demo.
- `document/android/implementation_summary.md` — Short index of implementation details.
- `document/android/testing_and_validation.md` — Testing, validation checklist and visual checks.
- `document/android/troubleshooting_and_fixes.md` — Troubleshooting notes and important fixes.

For model assets and examples remain under `app/src/main/assets/models/` and `android-app/output/`.

If you need the older, detailed Chinese guides that were previously in this directory, they have been archived or removed per project cleanup policy.
